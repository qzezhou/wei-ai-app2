约定：β = v/c，γ = 1/√(1 − β2)； 取 c = 3.00 × 108 m/s。洛伦兹变换： Δx′ = γ(Δx − vΔt)， Δt′ = γ(Δt − vΔx/c2)。

第 1 题　事件的相对论性倒序（Fig. 37-15）Problem 1

已知：在无撇系 S 中，事件 A 先于 B，时间间隔 Δt = 1.00 μs，空间间隔 Δx = 400 m。 带撇系 S′ 以速度 v = βc 沿 +x 方向运动。

求：Δt′ 的表达式与图像；Δt′ = 0 时的 β；次序不变与反转的 β 范围；A 能否导致 B。

解
(a) 由洛伦兹变换，取两事件坐标差：
Δt′ = γ(Δt − vΔx/c2) = γ(Δt − βΔx/c)
Δx/c = 400 / (3.00×108) = 1.33×10−6 s = 1.33 μs，
故 Δt′ = γ(1.00 − 1.33β) μs。
(b) 当 0 ≤ β ≤ 0.01 时，γ ≈ 1，故 Δt′ ≈ (1.00 − 1.33β) μs：由 1.000 μs 缓降至 0.987 μs， 图像为一条近似水平的直线。
(c) 当 0.1 ≤ β < 1 时，γ 迅速增大：
β = 0.1：Δt′ = 0.871 μs；　β = 0.5：0.385 μs；　β = 0.75：0；
β = 0.9：−0.459 μs；　β → 1 时 γ → ∞，Δt′ → −∞。
曲线由 0.871 μs 单调下降，在 β = 0.75 处穿过横轴，随后急剧下降并趋于负无穷。
(d) 令 Δt′ = 0，因 γ > 0，只需 1.00 − 1.33β = 0：
β = 1.00 μs1.33 μs = cΔtΔx = 0.750，　v = 0.750c
(e)(f) Δt′ > 0（次序相同）⇒ 0 ≤ β < 0.750； Δt′ < 0（次序反转，B 先发生）⇒ 0.750 < β < 1。
(g) 取 cΔt = 3.00×108 × 1.00×10−6 = 300 m。 因
cΔt = 300 m < Δx = 400 m，
两事件为类空间隔，不可能有因果联系。若 A 要通过信号影响 B，所需速度 vs = Δx/Δt = 4.0×108 m/s = 1.33c > c， 超过光速，故 A 不能导致 B，反之亦然。也正因二者无因果联系，其先后次序才可在不同惯性系中反转。
答
  • (a) Δt′ = γ(1.00 − 1.33β) μs；
  • (b) 近似直线，1.000 μs → 0.987 μs；
  • (c) 0.871 μs → 0（β = 0.75）→ 负值 → −∞（β → 1）；
  • (d) β = 0.750（v = 2.25×108 m/s）；
  • (e) 0 ≤ β < 0.750，A 仍先于 B；(f) 0.750 < β < 1，B 先于 A；
  • (g) 不能。cΔt = 300 m < Δx = 400 m，属类空间隔，需 1.33c 的超光速信号。

第 2 题　空间间隔 Δx′ 的极小值Problem 2

已知：同第 1 题，Δt = 1.00 μs，Δx = 400 m。

求：Δx′ 的表达式、图像、极小值位置与数值。

解
(a) 由 Δx′ = γ(Δx − vΔt)，并注意 cΔt = 300 m：
Δx′ = γ(400 − 300β) m
(b) 0 ≤ β ≤ 0.01 时 γ ≈ 1，Δx′ ≈ 400 − 300β， 由 400 m 缓降至 397 m，图像近似为水平直线。
(c) 0.1 ≤ β < 1 时先降后升：
β = 0.1：372 m；　β = 0.5：289 m；　β = 0.75：265 m（最小）；
β = 0.9：298 m；　β → 1 时 γ → ∞，Δx′ → +∞。
(d) 令 dΔx′/dβ = 0。写成 Δx′ = (400 − 300β)(1 − β2)−1/2，求导得
dΔx′dβ = −300(1 − β2) + β(400 − 300β)(1 − β2)3/2 = 0，
分子化简为 400β − 300 = 0，故
β = 300/400 = 0.750
（亦可由不变量判定：Δx′2 = Δx2 − c2Δt2 + c2Δt′2， 当 Δt′ = 0 时取极小，即 β = 0.750。）
(e) 此时 γ = 1.512，括号内为 175 m：
Δx′min = 1.512 × 175 = 265 m
或直接由不变量：
Δx′min = √(4002 − 3002) = √70000 = 265 m
此即两事件的固有距离。
答
  • (a) Δx′ = γ(400 − 300β) m；
  • (b) 400 m → 397 m，近似直线；
  • (c) 372 m → 265 m（β = 0.75）→ 快速上升 → +∞；
  • (d) β = 0.750；(e) Δx′min = 265 m。

第 44 题　米尺收缩与事件间隔Problem 44

已知：Bullwinkle 的手表走 10.0 s 对应地面 30.0 s。事件 1：x1 = 33.0 m，t1 = 22.0 ns； 事件 2：x2 = 53.0 m，t2 = 62.0 ns。 三把米尺分别平行于 x′、y′、z′ 轴。

求：三把尺的长度；两事件在他系中的空间、时间间隔及先后次序。

解
(0) 手表读数为固有时，故
γ = 30.0 s10.0 s = 3.00， β = √(1 − 1/γ2) = √(1 − 1/9) = 0.943， v = 2.83×108 m/s
(a) 尺 1 沿运动方向，发生长度收缩：
L1 = L0/γ = 1.00/3.00 = 0.333 m
(b)(c) 尺 2、3 垂直于运动方向，长度不变：
L2 = L3 = 1.00 m
(d) 两事件在 S 系中： Δx = 20.0 m，Δt = 40.0 ns。
Δx′ = γ(Δx − vΔt) = 3.00(20.0 − 2.83×108×40.0×10−9)
= 3.00(20.0 − 11.3) = 26.1 m
(e)
Δt′ = γ(Δt − vΔx/c2)
= 3.00[40.0×10−9 − (2.83×108 × 20.0)/(9.00×1016)] s
= 3.00(40.0 − 62.8)×10−9 s = −6.9×10−8 s ≈ −69 ns

校验：Δx′2 − c2Δt′2 ≈ 26.12 − 20.62 ≈ 257 m2， 与 Δx2 − c2Δt2 = 20.02 − 12.02 = 256 m2 相符。

(f) Δt′ < 0 表示 t′2 < t′1， 故事件 2 先发生。因 cΔt = 12.0 m < Δx = 20.0 m，两事件为类空间隔，次序可以反转。
答
  • (a) 0.333 m；(b) 1.00 m；(c) 1.00 m；
  • (d) Δx′ = 26 m；(e) |Δt′| = 69 ns（Δt′ = −6.9×10−8 s）；
  • (f) 事件 2 先发生。

第 53 题　π 介子的衰变高度Problem 53

已知：π 介子在海平面以上 120 km 处产生，总能量 E = 4.00×105 MeV，静止能量 mc2 = 139.6 MeV，固有寿命 Δt0 = 35.0 ns，竖直向下运动。

求：在地球参考系中衰变处的高度。

解
1 由能量求 γ：
γ = Emc2 = 4.00×105139.6 = 2.865×103
β = √(1 − 1/γ2) ≈ 1 − 6.1×10−8 ≈ 1
2 时间膨胀：地球系中寿命为
Δt = γΔt0 = 2.865×103 × 35.0 ns = 1.003×10−4 s
3 飞行距离（v ≈ c）：
d = vΔt ≈ cΔt = 3.00×108 × 1.003×10−4 = 3.01×104 m = 30.1 km
4 衰变高度：
h = 120 − 30.1 = 89.9 km ≈ 90 km

（π 介子系验证：大气厚度收缩为 120 km/γ = 41.9 m，35 ns 内飞行 10.5 m， 剩余 31.4 m 折回地球系为 31.4γ ≈ 9.0×104 m = 90 km，结果一致。）

答
  • 衰变发生在海平面以上 约 90 km（89.9 km ≈ 8.99×104 m）处。

第 58 题　由图像求速度叠加Problem 58

已知：粒子 P 相对 S 系以确定速度 u 沿 x 轴运动； S′ 系以速度 v 沿 x 轴运动。图 37-20b 给出 u′ 随 v 的变化， 纵轴刻度由 u′a = 0.800c 标定。

求：(a) v = 0.95c 时的 u′；(b) v → c 时 u′ 的极限。

解
1 当 v = 0 时两系重合，u′ = u。 由图得截距 u = u′a = 0.800c。
2 相对论速度变换：
u′ = u − v1 − uv/c2 = 0.800 − β1 − 0.800β×c
(a) 代入 β = 0.950：
u′ = 0.800 − 0.9501 − 0.800×0.950×c = −0.1500.240×c = −0.625c
负号表示粒子在 S′ 中沿 −x′ 方向运动，速率为 0.625c。
(b) 令 β → 1：
u′ → 0.800 − 1.0001 − 0.800×c = −0.2000.200×c = −c
相对速率的大小始终不超过光速。
答
  • (a) u′ = −0.625c；(b) u′ → −c。
