# 《喂！AI》移动端网页 App 实施计划

## 一、产品定位

一句话：**像刷短视频一样刷 AI 知识，刷着刷着把一个铁疙瘩喂成智能机器人。**

- 形态：手机网页 App（PWA），浏览器打开后可"添加到主屏幕"，全屏运行、可离线，无需上架、无需账号。
- 用户：单人使用（本人），数据保存在手机本地（localStorage）。
- 目标场景：随时打开，单次 3~10 分钟，每日目标 **10 张知识卡**（约 8 分钟）。
- 内容方向：AI 原理科普（神经网络、大模型、幻觉、RAG 等）+ AI 实用技能（提示词、AI 工具、避坑）。
- 画风：萌系圆滚滚机器人 + 霓虹科技光效，竖屏深色界面。

## 二、核心玩法（已与用户确认）

### 1. 短视频式知识流
- 竖屏全屏、上下滑动（CSS scroll-snap），手感对齐短视频。
- 每张卡 = 30~60 秒：一句话钩子标题 + 大白话讲解（含类比）+ 主题表情/图形视觉（纯 SVG/CSS 绘制，保证离线可用、风格统一，不用外链图片）。
- 每刷 3~4 张知识卡，插入 1 道针对刚看过内容的选择题：答对 = 真正"消化"，获得数据能量（机器人经验）；答错展示解析，不扣血不惩罚，可继续。

### 2. 连胜（Streak）
- 每日消化满 10 张卡 = 当日打卡成功，连胜天数 +1，首页火焰数字。
- 周补签卡：每自然周自动获得 1 张；断签次日打开时弹窗提示使用，连胜不中断。
- 不做"超额惩罚"，只做正反馈。

### 3. 抽卡（Gacha）
- 完成每日目标 → 获得 1 张抽卡券（当日多刷不再得，防止沉迷）。
- 奖池 = 机器人装备/外观（头部、身体、配饰、光环 4 个槽位）。
- 稀有度：N 60% / R 25% / SR 12% / SSR 3%；保底：10 连必出 SR+，50 连必出 SSR。
- 抽卡动画：霓虹光门 + 稀有度颜色（N 灰蓝 / R 蓝光 / SR 紫光 / SSR 金光闪烁）。
- 重复装备自动转化为"升级碎片"（后续可用于升级装备，v1 只累积显示）。

### 4. 养成
- 机器人随累计"数据能量"升级，基础形态分 5 阶：
  铁疙瘩 Lv1 → 带电小盒子 Lv2 → 圆屏机器人 Lv3 → 喷气智能体 Lv4 → 全息 AI 生命 Lv5（每阶外观变化由 SVG 部件切换实现）。
- 抽到的装备可穿戴，机器人形象 = 基础形态部件 + 装备部件实时合成。
- 首次启动可给机器人起名。

### 5. 知识图鉴
- 按"原理科普 / 实用技能"分类展示全部卡片网格，已消化的点亮、未消化的显示剪影。
- 显示收集进度（X/Y），点击已收集卡片可回看。

### 6. 机器人对话（离线预设）
- 首页机器人有对话气泡，根据**最近消化卡片的标签**（如 neuralnet、prompt、llm）从预设台词库取一句话：吐槽、抛追问、或再考一道小题。
- 连胜/断签/久未打开也有对应台词。纯本地规则，不联网、零成本，未来可接真实大模型。

## 三、技术方案

纯静态站点，**零构建、零依赖、零后端**：原生 HTML + CSS + ES Module JS。数据用本地 JS/JSON 内容库。用 Python 内置 HTTP 服务器在局域网提供手机访问。

### 文件结构

```
自建app/
├── index.html                  # 单页入口（首页/信息流/图鉴/抽卡四个 Tab）
├── manifest.webmanifest        # PWA 清单
├── sw.js                       # Service Worker（App Shell + 内容离线缓存）
├── assets/
│   └── icons/                  # PWA 图标（SVG + 192/512 PNG，PowerShell 生成）
├── css/
│   └── style.css               # 设计系统：深色霓虹、卡片、动效、安全区适配
└── js/
    ├── main.js                 # 启动、Tab 路由、首访引导
    ├── store.js                # localStorage 状态读写、日期/连胜逻辑、版本迁移
    ├── content.js              # 知识卡 + 测验题库（初始 ≥50 张）
    ├── gacha-data.js           # 装备奖池、稀有度、权重、台词库
    ├── feed.js                 # 竖滑信息流、卡片渲染、插入测验
    ├── quiz.js                 # 选择题交互与判定
    ├── robot.js                # SVG 机器人合成（形态+装备+稀有度光效）
    ├── gacha.js                # 抽卡动画、保底、背包、穿戴
    ├── home.js                 # 首页：每日进度、连胜火焰、气泡对话
    └── dex.js                  # 图鉴页
```

### 本地状态结构（store.js）

```js
{
  version: 1,
  robotName: "小铁",
  xp: 0,                       // 数据能量（决定等级/形态）
  digestedIds: [],             // 已消化卡片 id
  quizCorrect: {cardId: bool},
  seenIds: [],                 // 刷到过的卡片（控制出题与不重复推送）
  feedOrder: [],               // 本次洗牌顺序，刷完重新洗牌
  streak: { count, lastDate, freezeCards, weekKey },
  daily: { date, digestedCount, ticketClaimed },
  gacha: { tickets, pity10, pity50, inventory: {partId: count}, equipped: {head,body,accessory,aura} },
  chat: { lastTag, lastLineIdx }
}
```

### 内容库规范（content.js）

每张卡一个对象，初始 **50 张**（原理 26 + 技能 24），例如：

```js
{
  id: "p01",
  cat: "principle",            // principle | skill
  tag: "neuralnet",
  title: "神经网络其实就是一层一层的\"打分器\"",
  body: "……大白话 80~150 字，必含一个生活类比……",
  emoji: "🧠",
  quiz: { q: "……", options: ["…","…","…","…"], answer: 1, why: "解析一句话" }
}
```

主题覆盖：神经元/权重、训练与损失函数、深度学习、Token、词嵌入、Transformer（直觉版）、大语言模型、预训练/微调、幻觉、温度参数、RAG、Agent、多模态、扩散模型、RLHF、AI 发展史名场面；提示词四要素（角色/背景/示例/迭代）、常见提示词模板、AI 工具地图（对话/搜索/写作/编程/绘画）、结果核查方法、隐私避坑、用 AI 学英语/做笔记/读论文/编程入门等。

## 四、实施步骤（按依赖顺序）

1. 搭建目录骨架、`index.html` 单页四 Tab 框架、`manifest` + `sw.js` + 图标。
2. 写 `style.css` 设计系统：深色底、霓虹主色、卡片样式、火焰/稀有度色板、动效（弹出、闪光、滑动过渡）、iPhone 安全区。
3. 写 `store.js`：状态存取、每日重置、连胜判定、补签卡发放与使用、XP/等级换算。
4. 写 `content.js`：50 张知识卡（含测验题与解析）。
5. 写 `gacha-data.js`：4 槽位 × 多稀有度装备（约 24 件）、权重、保底、标签台词库。
6. 写 `feed.js` + `quiz.js`：全屏竖滑、每 3~4 张插测验、答对发 XP 并记入消化、进度同步首页。
7. 写 `robot.js`：SVG 部件系统，5 阶形态 + 装备槽位合成 + SSR 光环特效。
8. 写 `home.js`：火焰连胜、每日进度环、机器人气泡（标签台词）、领奖入口。
9. 写 `gacha.js`：抽卡券消耗、光门动画、稀有度揭晓、保底、背包穿戴。
10. 写 `dex.js`：分类图鉴网格、剪影/点亮、回看弹层。
11. 首访引导：起名 + 30 秒玩法说明；断签补签弹窗。
12. 启动局域网 HTTP 服务，真机 + 浏览器移动模拟双重验证（见下）。

## 五、验证方式

- 用 `python -m http.server` 在本机启动服务，浏览器移动设备模拟器走查：首访引导 → 刷卡 → 测验答对/答错 → 每日 10 张领奖 → 抽卡（含动画）→ 穿戴 → 图鉴点亮 → 机器人台词。
- 控制台改本地日期/状态模拟：跨天连胜、断签补签弹窗、10 连/50 连保底、升级换形态。
- 刷新页面验证状态持久化；断网验证 Service Worker 离线可用。
- 手机真机同局域网访问验证竖屏手势与"添加到主屏幕"（如遇防火墙拦截，以模拟器验证为准并附手机访问说明）。

## 六、风险与处理

- **手机无法访问局域网**：Windows 防火墙拦截 → 提供放行命令或改用桌面模拟器验证，后续可免费部署到 GitHub Pages。
- **iOS 对 PWA 支持差异**：SVG/PNG 双图标兜底；核心功能不依赖 PWA，浏览器直接打开也完整可用。
- **SVG 机器人部件组合复杂度**：采用固定画布 + 分层简单几何图形（眼睛/天线/机身/喷气/光环），装备只改对应图层，不做任意变换。
- **内容量**：首批 50 张保证 5 天以上新鲜度；`content.js` 为纯数据结构，后续加卡只需追加对象，不改逻辑。
- **刷卡变成新的"刷视频"**：每日仅完成目标给抽卡券、无内容自动连播、需答题才算消化，用主动回忆替代被动划走。
